# MIRSAD FREE 1.1 Mobile Ready — منصة مرصاد الذكية

## ما الجديد في 1.1؟
هذه النسخة مبنية على MIRSAD FREE 1.0 Mobile Ready، مع إضافة **تهيئة تلقائية لقاعدة البيانات عند بدء الخدمة** حتى لا تحتاج إلى Render Shell أو خطة مدفوعة.

عند تشغيل الخدمة، يقوم `startup.js` بشكل idempotent بـ:
1. إنشاء/تحديث جداول قاعدة البيانات من `db/schema.sql`.
2. إدخال وتحديث **49 مؤشرًا للمدارس الحكومية** من `db/indicator-seed.json`.
3. تسجيل بصمة مجموعة المؤشرات في `indicator_versions`.
4. إنشاء/تحديث حساب مالك المنصة إذا كانت متغيرات `BOOTSTRAP_OWNER_*` موجودة.
5. تشغيل خادم MIRSAD بعد نجاح التهيئة.

لا تُحذف البيانات الموجودة؛ أوامر الإنشاء والإدخال مصممة لتكون قابلة لإعادة التشغيل.

## النشر على Render Free
1. ارفع محتويات هذه المجلد إلى مستودع GitHub جديد أو استبدل ملفات المستودع الحالي.
2. اجعل Render يستخدم:
   - Build: `npm install --omit=dev --no-audit --no-fund`
   - Start: `npm start`
3. في Environment Variables أضف:
   - `DATABASE_URL` = Internal Database URL لقاعدة PostgreSQL.
   - `JWT_SECRET` = سر عشوائي قوي (32 حرفًا على الأقل، والأفضل 64+).
   - `BOOTSTRAP_OWNER_EMAIL` = بريد مالك المنصة.
   - `BOOTSTRAP_OWNER_PASSWORD` = كلمة مرور قوية لا تقل عن 12 حرفًا.
   - `BOOTSTRAP_OWNER_NAME` = اسم المالك (اختياري، الافتراضي مالك منصة مرصاد).
   - `AUTO_SEED_INDICATORS=true`.
4. نفّذ Deploy.
5. راقب Logs. يجب أن تظهر رسائل قريبة من:
   - `Database initialized. Indicators ready: 49.`
   - `Owner account ready: ...` إذا كانت بيانات المالك موجودة.
   - `MIRSAD listening on :3000` أو المنفذ الذي يحدده Render.
6. بعد نجاح أول نشر، يمكن حذف `BOOTSTRAP_OWNER_EMAIL` و`BOOTSTRAP_OWNER_PASSWORD` من Render إذا أردت جعل إنشاء الحساب عملية لمرة واحدة. **لا تحذف DATABASE_URL أو JWT_SECRET.**

## قاعدة المؤشرات
المصدر: وثيقة **هيئة تقويم التعليم والتدريب – الدليل التنفيذي لمعايير (التقويم والاعتماد المدرسي) – الإصدار الثاني – للعام الدراسي 1447هـ / 2026م**.

هذه النسخة تستخدم مجموعة الـ49 مؤشرًا للمدارس الحكومية، ولا تُدخل المؤشرات الثلاثة ذات النجمة الخاصة بالمدارس الأهلية والعالمية.

## تشغيل محلي
```bash
npm install
DATABASE_URL=... JWT_SECRET=... BOOTSTRAP_OWNER_EMAIL=admin@example.com BOOTSTRAP_OWNER_PASSWORD='CHANGE_ME_12_PLUS' npm start
```

## الوظائف الرئيسية
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- تسجيل دخول JWT.
- حساب مالك للمنصة.
- مساحات مستقلة للمدارس.
- إنشاء مدرسة وحساب مديرها من حساب المالك.
- رفع PDF / Word / Excel / TXT / PNG / JPG.
- استخراج النص وOCR للصور عند توفر Tesseract.
- SHA-256 لمنع تكرار الملف داخل المدرسة.
- محرك مرصاد لتحليل الشاهد وربطه بعدة مؤشرات.
- عرض مواضع الإثبات على مستوى الجملة.
- حساب قوة الإثبات واكتمال الأبعاد.
- اقتراح فجوات وشواهد مكملة.
- مراجعة بشرية واعتماد/رفض الربط.
- سجل تدقيق وتقارير قابلة للطباعة.

## ملاحظات تشغيلية مهمة
- خطة Render Free مناسبة للاختبار والتجربة وليست ضمانًا لاستمرارية خدمة إنتاجية دائمة.
- تخزين الملفات المحلي داخل حاوية الخدمة قد لا يكون مناسبًا كحل تخزين دائم عند إعادة النشر/إعادة التشغيل؛ للتوسع التجاري استخدم Object Storage خاصًا.
- فعّل نسخًا احتياطية واختبار استعادة لقاعدة البيانات عند الانتقال للإنتاج الفعلي.
- لا تعتبر نتيجة التحليل الآلي قرار اعتماد رسمي؛ المراجعة البشرية جزء من سير العمل.
- لا توجد كلمة مرور ثابتة مضمنة داخل الكود.
