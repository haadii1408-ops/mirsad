# مِرصاد MIRSAD — Free 1.0 Mobile Ready

منصة ذكاء الشواهد المدرسية. هذه الحزمة مهيأة للرفع من الهاتف إلى GitHub ثم النشر على خدمة استضافة تدعم Node.js.

## التشغيل
- Node.js 22+
- PostgreSQL
- متغير DATABASE_URL
- متغير JWT_SECRET بطول 32 حرفًا على الأقل

## الرفع من الجوال
استخدم ملف MOBILE_GITHUB.md. الملفات التشغيلية الأساسية موجودة في جذر الحزمة.

## تحذير التخزين
التخزين المحلي للملفات في استضافات مجانية قد يكون مؤقتًا؛ لا تعتمد عليه لحفظ شواهد رسمية دائمة قبل ربط تخزين ملفات دائم.
